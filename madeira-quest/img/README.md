# Fotos der Orte

Lege hier Fotos der Orte ab (am besten **JPG, ca. 1200 px breit, unter 300 KB**) und trage sie in `data.js` beim Ort ein:

```js
photos: ["img/caco-1.jpg", "img/caco-2.jpg", "img/caco-3.jpg"],
photoCredit: "Photo: Lena",
```

Nur eigene Fotos oder Fotos mit freier Lizenz (z. B. Wikimedia Commons, Urheber in `photoCredit` nennen).
**Keine Fotos aus Google Maps kopieren** – die sind urheberrechtlich geschützt.
